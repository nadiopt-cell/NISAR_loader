# Валидация NISAR DiD-детектирования ветровалов на НОВЫХ участках БД Шихова (октябрь 2026)

Вторая волна валидации L-band DiD-метода плагина NISAR_loader v0.3.1:
4 новых сайт-группы (32 события) из обновлённой БД Шихова (ветровалы_3316,
изд. 2026-09-06), не входившие в первую валидацию (karpinsk / sverdlovsk /
kostroma / velsk). Ground truth — события NISAR-эры (июнь–июль 2026)
с точностью даты до дня; отбор участков по покрытию GUNW (горизонт данных
сентябрь 2026).

## Протокол

Тот же, что в первой валидации (см. `upload/nisar_val/README.md`):

1. Пара GUNW-гранул одного трека/кадра: **шторм-пара** (интервал содержит
   даты событий) + смежная **контроль-пара** (без событий); при отсутствии
   12-суточной шторм-пары используются 24-суточные пары **согласованно**
   (шторм и контроль одинакового базиса).
2. Живой код плагина `run_windthrow_did` (порог absolute = median(bg)+0.25,
   медиана 3×3, мин 6 px), ref_mask — растеризованные полигоны Шихова
   (все события кадра в интервале шторм-пары (t0, t1]), лесная маска
   Hansen GFC@2026 (доля 30-м лесных пикселей ≥ 0.5 — семантика v2/v3,
   эквивалентность 99.96% доказана в первой валидации).
3. Метрики: сигнал (AUC Mann–Whitney, excess, TPR@FPR 5%); пиксельные
   P/R/F1/IoU (лес&валид); локальные P/R/F1 в буфере 3 км; объектные
   P/R/F1 при IoU ≥ 0.5 (объект-референс = событие).

Скрипт: `nisar_validate_new.py` (регрессионно верифицирован ретестом
Карпинска на уцелевшей паре трк093D фр058: best_iou события 4251 =
**0.1556 — совпадение с первой валидацией до 4-го знака**).

## Выводы

- **Сигнал L-band DiD подтверждён на 2 из 4 новых сайт-групп сильно**
  (Кострома AUC 0.920, Киров 0.968/excess 0.394 — рекорд обеих валидаций)
  и слабо на 2 (Нижний 0.807, Челябинск 0.825). По событиям: 3 из 4 групп
  имеют AUC ≥ 0.82, суммарно 26 из 32 событий — в кадрах с AUC ≥ 0.82.
- **Первый объектный матч**: смерч 4272 (Костромская, 15 га) — IoU 0.559,
  перекрытие 79%. У крупных шквалов Кирова перекрытие 0.88–0.93 при
  IoU 0.07–0.13 (блобы систематически крупнее полигонов — та же картина,
  что в первой валидации).
- **Слабые сайты коррелируют с высоким фоном dcoh**: медиана фона 0.109
  (Нижний) и 0.174 (Челябинск) против 0.048 (Киров) и 0.09 (Кострома) —
  контрольный период когерентнее штормового (погода/влажность), порог
  absolute +0.25 от завышенного фона недостижим для слабых событий.
  Подтверждена рекомендация первой валидации: калибровать a_coh ≈ 0.15–0.20
  (или адаптивный порог от MAD).
- **24-суточные пары валидны**: Киров (обе пары 24 сут) дал сильнейший
  сигнал — при базис-согласованности пар DiD работает и на 24 сут.
- **Геометрия захвата влияет**: события 4282/4283 (Нижегородская) на
  восходящем треке 99 не видны (overlap 0.00), на нисходящем треке 108 —
  перекрытие 0.32/0.49. Для слабых событий желателен мульти-трек.
- Челябинск: событие 4265 (157 га) на краю кадра при пороге 0.424
  (фон 0.174) — R_px 0.04; в контроль-интервале кадра есть паразитное
  событие 4299-класса (см. parasitic_events_in_control в validation.json).
