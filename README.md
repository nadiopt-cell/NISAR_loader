# NISAR Vegetation — QGIS plugin

Поиск, открытие и обработка продуктов NASA NISAR L-диапазона (GCOV + GUNW)
в QGIS: мониторинг растительности (HV в дБ, cross-ratio, RVI), обнаружение
ветровалов (DiD когерентности), экспорт в GeoTIFF/COG.

**Статус:** experimental MVP (v0.3.0). Совместимость: QGIS 3.28 LTR+ и
QGIS 4.x (только `qgis.PyQt`). **Валидирован на реальных гранулах**
(GCOV: поиск → скачивание → чтение → индексы; GUNW: пара 12-суточных
интерферограмм → DiD-конвейер ветровалов; детали —
`docs/product_notes.md`).

## Возможности

| Модуль | Что делает |
|---|---|
| **Search** | Поиск сцен GCOV и GUNW в ASF DAAC (extent карты, даты) — в фоне, с отменой |
| **Preview** | Превью до скачивания: quicklook-миниатюра ASF (анонимно, ~9 КБ), детали сцены (орбита/кадр/поляризации/размер), footprint на карте (QgsRubberBand) и «К границам сцены» по двойному клику |
| **Download** | Очередь скачивания с прогрессом (Earthdata Login через `~/.netrc`) |
| **Open** | Инспектор слоёв локального `.h5` (GCOV и GUNW: когерентность 80/20 м, фаза, маски), загрузка выбранных слоёв в проект с правильным CRS (группа «NISAR / …») |
| **Processing** | Пресеты: HV (cross-pol) в дБ, cross-ratio HV/HH, RVI (dual/full-pol — формула выбирается автоматически) — тайлово, Float32 |
| **Windthrow (DiD)** | Обнаружение ветровалов по разности разностей когерентности пары GUNW: штормовая + контрольная пара одного трека/кадра, адаптивный порог (медиана + 0.25·MAD), маска леса Hansen GFC, метрики AUC/excess/TPR@FPR5% по референс-полигонам, экспорт dcoh + маска + отчёт JSON (+ векторизация) |
| **Export** | Экспорт слоёв в GeoTIFF / COG (Float32, значения не искажаются) |
| **Processing Toolbox** | `nisar:hv_db`, `nisar:cross_ratio`, `nisar:rvi`, `nisar:export`, `nisar:windthrow_did` |

Плагин предупреждает о BETA-продуктах (не полностью откалиброваны) и не
смешивает их silently с PROVISIONAL.

## Установка

1. QGIS → **Plugins → Manage and Install Plugins → Install from ZIP** →
   выбрать `nisar_qgis_plugin_v0.3.0.zip`.
2. Появится тулбар «NISAR Vegetation» и пункт меню. Processing-алгоритмы —
   в Toolbox под группой «NISAR Vegetation».

### Необязательные Python-пакеты

Плагин работает без них (с честными сообщениями о том, чего не хватает):

```bash
python -m pip install h5py          # резервный читатель HDF5 (A3)
python -m pip install asf_search    # онлайн-поиск и скачивание ASF (B2)
```

### Earthdata Login (для скачивания)

Создайте `~/.netrc` (права 600):

```
machine urs.earthdata.nasa.gov
  login ВАШ_EDL_ЛОГИН
  password ВАШ_EDL_ПАРОЛЬ
```

Плагин **никогда** не хранит пароли в настройках/проекте.

## Быстрый старт (MVP-сценарий)

1. Открыть диалог плагина → вкладка **Search** → «Взять экстент карты» →
   даты → **Search**.
2. Кликнуть строку результата — превью сцены: quicklook-миниатюра
   (загружается анонимно, `~/.netrc` не нужен), детали (орбита, кадр,
   поляризации, размер), footprint на карте; двойной клик — зум к границам.
3. Отметить сцену → вкладка **Download** → **Скачать** (нужен `~/.netrc`).
4. Вкладка **Open** → выбрать скачанный `.h5` → в таблице слоёв отметить
   HHHH/HVHV → **Добавить в проект**.
5. Вкладка **Processing** → выбрать пресет (справа — «Что это?»: формула,
   как читать, ограничения) → **Вычислить**.
6. Вкладка **Export** (или `nisar:export` в Toolbox) → GeoTIFF/COG.

### Ветровалы (DiD) — быстрый старт

1. Найти и скачать **две** гранулы GUNW одного трека/кадра (вкладка
   **Search**, тип продукта GUNW): штормовую пару (интервал накрывает
   дату шторма) и контрольную (соседний 12-суточный интервал без шторма).
2. Вкладка **Windthrow (DiD)** → указать оба файла и дату шторма →
   **Найти ветровалы**. Маска Hansen GFC подтягивается онлайн автоматически.
3. На выходе: `dcoh.tif`, `windthrow_mask.tif`, `windthrow_report.json`
   (порог, выборки, флаги, метрики) и, опционально, GeoPackage с полигонами.

⚠️ Границы метода (по валидированной методике-первоисточнику): след
шириной менее трёх пикселей сетки 80 м (~240 м) не детектируется — для
узких следов торнадо используйте 20-м слои (`nisar:export` → coherence
20 м); метрики AUC/excess/TPR требуют референс-полигонов повреждений.

## Разработка

```bash
# юнит-тесты ядра — без QGIS и без GDAL
python -m pytest tests/unit -v

# статическая проверка относительных импортов
python scripts_import_check.py
```

Структура:

```
nisar_qgis/            # сам плагин (этот каталог попадает в установочный ZIP)
  nisar_core/          # ядро без QGIS: readers (A1/A2/A3), access (B1/B2/B3),
                       # processing (индексы, экспорт), models, presets, config
  gui/                 # диалог + фоновые QgsTask
  algorithms/          # Processing-алгоритмы
  i18n/                # en (по умолчанию) / ru
  resources/           # icon.png
tests/unit/            # pytest: синтетический GCOV в tmp_path (без бинарников в git)
tests/qgis/            # инструкции по интеграционной проверке в QGIS
docs/product_notes.md  # проверенные факты о структуре GCOV (источники + статус)
AGENTS.md              # исходное задание
```

### Что проверено, а что нет

Подробности — в `docs/product_notes.md` (кратко):

* ✅ пути слоёв/единицы/CRS — по официальному спецификатору
  JPL D-102274 Rev E и nisar-docs.asf.alaska.edu;
* ✅ поиск ASF — на живом SearchAPI (2026-09-29); исправлен баг:
  `asf_search` 14.x `search()` не принимает `session` — сессия теперь
  в `ASFSearchOptions`;
* ✅ **превью до скачивания — на живых данных** (2026-09-30):
  официальный набор browse ASF (`properties.browse`: миниатюра ~9 КБ,
  полный LATLON, NATIVE, по-полевые), миниатюры доступны анонимно,
  footprint Polygon (EPSG:4326) рисуется на канвасе (end-to-end через
  производственный код `B2ASFSearchBackend`);
* ✅ **скачивание, чтение и расчёт индексов — на реальном грануле**
  NISAR GCOV UR (251.7 МБ, frequencyB, V-дуал VHVH+VVVV, EPSG:32605,
  2026-09-30): статистика чтения совпала с атрибутами файла (< 0.001%),
  найденные особенности формата закрыты юнит-тестами
  (`tests/unit/test_real_granule_behaviors.py`);
* ⚠️ установка в реальный QGIS и `NETCDF:`-обход на GDAL 3.6–3.12 —
  требуют проверки на машине с QGIS (тест-сценарий в `tests/qgis/README.md`).

## Ограничения MVP

* Временные ряды, детектор изменений, спекл-фильтр, поляриметрия —
  зарегистрированы как пресеты, но помечены «позже» (P3, см. AGENTS.md).
* Для локально открытых файлов статус BETA/PROVISIONAL неизвестен —
  в файле нет явного флага (см. product_notes.md).
* QML-стили не поставляются; применяется программная растяжка 2–98%.

## Замечания для мейнтейнера

* В `nisar_qgis/metadata.txt` замените author/email/repository на
  реальные перед публикацией.
* Дополнительная зависимость GDAL используется только для записи
  GeoTIFF внутри QGIS (всегда доступна в QGIS).
